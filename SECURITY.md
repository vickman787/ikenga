# Security — Ikenga

Step 1 is a skeleton. It moves **no real money** and must not be treated as
production code.

- No private keys, mnemonics, or API secrets are in this repo, and none are
  generated by any script here. `.env` is gitignored; only `.env.example`
  (no secrets) is committed.
- `packages/payments` is a stub in Step 1: every function that would settle a
  payment returns a stub result or throws. Nothing in Step 1 signs, sends, or
  settles a transaction on any chain.
- `contracts/` is a Foundry skeleton with placeholder logic, marked in every
  file. It is **not audited and not deployed**. Do not send funds to any
  address derived from this code.
- The CFO pricing function in `packages/shared` is deterministic code. No
  language model is involved in any money decision, by design.
- To report a security issue, open a GitHub issue on the project repo and do
  not include secrets or private keys.
